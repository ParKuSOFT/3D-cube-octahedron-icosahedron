# 3D-cube-octahedron-icosahedron
3D models of a cube, octahedron, and icosahedron using OpenTK technology in C#
Lab #1

Each task must depict either a dodecahedron, an icosahedron, or a sphere. Additionally, two additional objects must be included: a tetrahedron, an octahedron, a cube, and a pentagonal bipyramid. Each task must include no more than two light sources. The entire scene and each individual object must also be rotated.
Task 8
Objects: Icosahedron, Cube, Octahedron.
Lighting: One of the lights must rotate in the YZ plane.
